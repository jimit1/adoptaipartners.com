# Embedded font notice

`index.html` embeds two typefaces as base64 `@font-face` data URIs so the page is fully
self-contained and makes no external requests.

| Font | Use | Licence |
|---|---|---|
| **Manrope** | Headings and body | SIL Open Font License 1.1 |
| **JetBrains Mono** | Labels, figures, mono UI | SIL Open Font License 1.1 |

Both are licensed under the **SIL Open Font License, Version 1.1**, which permits
embedding in documents and web pages, including for commercial use.

The OFL requires that the fonts are not sold on their own and that any derivative fonts do
not use the reserved names. Neither applies here: the files are embedded unmodified, purely
to render this page.

- Manrope: https://github.com/sharanda/manrope
- JetBrains Mono: https://github.com/JetBrains/JetBrainsMono
- OFL 1.1: https://openfontlicense.org

The subsetted WOFF2 files were taken from the local build output of the Abmatic AI
marketing site, which uses the same two families. Using them here keeps Adopt AI
typographically consistent with Abmatic AI.
